# אפליקציית האוהדים של הפועל ירושלים 🏀

פרויקט קהילתי לבניית אפליקציית האוהדים החינמית הטובה ביותר למועדון הכדורסל הפועל ירושלים.

## סטטוס: שלב 0 — עיצוב משותף

לפני שכותבים שורת קוד אחת, אנחנו מגדירים יחד את המטרות, ההיקף והאמצעים של האפליקציה באמצעות שאלון אינטראקטיבי:

- **השאלון:** [`docs/codesign/questionnaire.html`](docs/codesign/questionnaire.html) — עמוד ווב עצמאי (עברית, RTL) עם שמונה שלבים: חזון ומטרות, קהל יעד, היקף פיצ׳רים, תוכן ומקורות מידע, פלטפורמה ואמצעים, קהילה ומעורבות, עיצוב וזהות, הצלחה ואילוצים.
- בסוף השאלון מתקבל סיכום תשובות בפורמט Markdown להעתקה — התשובות יהפכו למסמך האפיון של גרסה 1.

## מפת דרכים

1. **שלב 0 — שאלון עיצוב משותף** (כאן אנחנו)
2. שלב 1 — מסמך אפיון ומפת דרכים לגרסה ראשונה
3. שלב 2 — בניית גרסה ראשונה
4. שלב 3 — פידבק מאוהדים ושיפורים
