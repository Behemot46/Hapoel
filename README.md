# אפליקציית האוהדים של הפועל ירושלים 🏀

פרויקט קהילתי לבניית אפליקציית האוהדים החינמית הטובה ביותר למועדון הכדורסל הפועל ירושלים.

## סטטוס: שלב 2 — בניית גרסה 1 (שלב א׳ מוכן)

**״האדומים מהבירה״** — אפליקציית ווב (PWA) בעברית: עמוד בית עם המשחק הבא והתוצאה האחרונה, לוח משחקים ותוצאות, וטבלת הליגה. עובדת גם בלי אינטרנט וניתנת להתקנה למסך הבית.

### מבנה הריפו

- [`app/`](app/) — האפליקציה עצמה (HTML/CSS/JS, ללא תלות בכלים חיצוניים). הנתונים בקבצי JSON תחת [`app/data/`](app/data/).
- [`scripts/update_data.py`](scripts/update_data.py) — אוסף הנתונים האוטומטי (רץ ב־GitHub Actions שלוש פעמים ביום).
- [`.github/workflows/`](.github/workflows/) — פרסום האתר לחינם ב־GitHub Pages + עדכון הנתונים המתוזמן.
- [`docs/spec/v1-spec.md`](docs/spec/v1-spec.md) — מסמך האפיון של גרסה 1. השאלון שממנו נולד: [`docs/codesign/questionnaire.html`](docs/codesign/questionnaire.html).

### איך מעלים לאוויר (חד־פעמי)

1. ממזגים את הענף הזה ל־`main`.
2. בהגדרות הריפו: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. בסיום הפרסום האתר יעלה לכתובת `https://behemot46.github.io/Hapoel/`.
4. מפעילים ידנית את ה־workflow ״עדכון נתונים אוטומטי״ (לשונית Actions) כדי להתחיל את איסוף הנתונים; עד שהאיסוף מכויל, האפליקציה מציגה נתוני דוגמה מסומנים.
